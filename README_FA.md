# سپیدار آنلاین

بازطراحی کامل سامانه باشگاه مشتریان سپیدار به صورت وب‌سایت آنلاین با دیتابیس مرکزی PostgreSQL.

## امکانات نسخه 1.0
- ورود کاربران با نقش مدیر / اپراتور / فقط مشاهده
- داشبورد آنلاین
- مدیریت مشتریان و UID کارت
- شارژ اعتبار مشتری
- تعریف و ویرایش طرح‌ها: شماره طرح، مبلغ پرداختی، اعتبار نهایی، تعداد هفته، سقف مصرف هفتگی
- فعال‌سازی طرح روی مشتری
- مدیریت خدمات و قیمت‌ها
- فروش / کسر اعتبار با کنترل موجودی و سقف هفتگی طرح
- ثبت فاکتور و اقلام هر فاکتور
- تراکنش‌ها و ریزکارکرد فیلترپذیر
- مدیریت بازاریاب‌ها، درصد پورسانت برای هر خدمت، موجودی، برداشت و سوابق
- حسابداری درآمد و هزینه
- تنظیمات مجموعه و واحد پول
- کاربران چندنقشی
- دیتابیس PostgreSQL واقعی و مرکزی
- طراحی RTL و واکنش‌گرا برای موبایل و دسکتاپ

## اجرای سریع با Docker روی سرور/VPS
1. Docker و Docker Compose را نصب کنید.
2. پوشه پروژه را روی سرور کپی کنید.
3. مقادیر رمز دیتابیس، `JWT_SECRET` و `ADMIN_PASSWORD` را در `docker-compose.yml` عوض کنید.
4. اجرا:

```bash
docker compose up -d --build
```

سایت روی پورت 3000 اجرا می‌شود. برای دامنه واقعی، Nginx/Caddy را به عنوان reverse proxy و HTTPS روی دامنه تنظیم کنید.

## اجرای بدون Docker
PostgreSQL بسازید و سپس:

```bash
cp .env.example .env
npm install
npm start
```

مقدار `DATABASE_URL` را در `.env` با دیتابیس واقعی تنظیم کنید.

## نکته امنیتی بسیار مهم
قبل از انتشار عمومی حتماً `JWT_SECRET` و رمز مدیر پیش‌فرض را تغییر دهید. برای سایت عمومی نیز HTTPS اجباری است.

## استقرار روی Render / Railway
این پروژه به یک Web Service Node.js و یک PostgreSQL نیاز دارد. متغیرهای محیطی زیر را تنظیم کنید:

- `DATABASE_URL`
- `JWT_SECRET`
- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`
- `NODE_ENV=production`

فرمان Start: `npm start`

## معماری
مرورگر هیچ داده اصلی را در LocalStorage نگهداری نمی‌کند. تمام عملیات از طریق API سرور انجام شده و در PostgreSQL ذخیره می‌شوند؛ بنابراین کامپیوتر، موبایل و شعب مختلف در صورت ورود مجاز، یک دیتابیس مشترک را می‌بینند.
